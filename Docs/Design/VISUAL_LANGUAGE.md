## Visual Quietness

Application chrome must remain visually quiet.

The user's wallpaper is the visually dominant content.
The interface surrounding it should recede into the background.

Avoid creating large high-contrast surfaces solely to distinguish
functional regions.

Prefer subtle system background differences and 1px separators.

Avoid giving every interactive element equal visual weight.

Primary actions, secondary actions, contextual actions and passive
information must have clearly different levels of emphasis.

When too many elements have borders, backgrounds, or rounded containers,
remove decoration before adding more hierarchy.
