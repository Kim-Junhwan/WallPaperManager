# LiveWallpaper Design

This directory defines the UI/UX design language for the LiveWallpaper macOS application.

These documents are the source of truth for all design-related work.

Before designing, redesigning, or implementing any user-facing interface,
read the relevant documents in this directory.

## Required documents

Always read:

- DESIGN_PRINCIPLES.md
- MACOS_GUIDELINES.md
- COMPONENTS.md
- INTERACTION_GUIDELINES.md
- REFERENCES.md

Screen-specific requirements provided in the current task take precedence
over general layout suggestions in these documents.

However, screen-specific designs should still follow the overall design
language unless explicitly instructed otherwise.

---

## Product

LiveWallpaper is a native macOS application for importing, configuring,
previewing, and applying live or static wallpapers.

The application should feel like a mature desktop utility that users can
comfortably use every day.

The design must prioritize:

1. Native macOS behavior
2. Clear information hierarchy
3. Direct manipulation
4. Efficient desktop workflows
5. Appropriate information density
6. Visual restraint
7. Functional clarity

The goal is not to create an impressive design mockup.

The goal is to create believable, usable software.
